## Internal Developer Platform (IDP) with Red Hat Developer Hub

### 📖 Description

Learn how to build an **Internal Developer Platform (IDP)** using **Red Hat Developer Hub (RHDH)** to streamline application delivery, standardize workflows, and improve developer experience across your organization.

Red Hat Developer Hub enables platform engineering teams to deliver a self-service developer portal based on Backstage. With support for **GitOps**, **golden templates**, **API discovery**, and **observability dashboards**, RHDH is a powerful tool for building a scalable IDP.

---

### 🎯 Objectives

By completing this training, you will learn how to:

* Deploy **RHDH** and **Keycloak (RHBK)** using **ArgoCD GitOps**
* Integrate **GitHub authentication** with RHBK and RHDH
* Create and use **golden templates** (Spring Boot, React, PostgreSQL, etc.)
* Automate application deployments using **ArgoCD**
* Discover and document internal APIs using **OpenAPI** and **Tekton**
